# Rezunate AI Website

Source for [rezunate.ai](https://rezunate.ai), built with Angular and hosted on GitHub Pages from the `docs/` folder.

## Development

```bash
npm install
npm start          # dev server at http://localhost:4200
```

## Deploying

```bash
npm run build      # outputs the production site to docs/
```

Commit the updated `docs/` folder along with your source changes; GitHub Pages serves it at rezunate.ai.

## Editing content

Most page content (contact details, testimonials, social links, quotes) lives in `src/assets/data.min.js`.
